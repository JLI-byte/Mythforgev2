# LoreCanvas

A creative writing and worldbuilding tool for novelists, storytellers and
worldbuilders. Your work lives in the browser and syncs to your account.

## What It Does

LoreCanvas keeps your world bible inside your writing, not beside it.
Type `[[` anywhere in a scene to create a world entry without leaving your
writing flow, or `@` to link one you already have. Characters, locations,
factions, artifacts and lore all live alongside your manuscript.

## Core Features

- **Inline entity linking** — `[[` creates a world entry at the point of inspiration; `@` links an existing one
- **World Bible** — characters, locations, factions and lore beside the manuscript
- **Research boards** — a spatial canvas of notes, clippings and links, per project or per world
- **Compile & export** — assemble the whole manuscript with front matter and download it as Markdown, Word (.docx) or EPUB
- **Dark/light mode** — full theme support

## Account

Sign-in is by magic link and is currently invite-only, so an email has to be
invited before it can sign in. Work is kept in the browser and synced to your
account, so it follows you between devices.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Zustand
- Tiptap

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4000](http://localhost:4000) to start writing.
